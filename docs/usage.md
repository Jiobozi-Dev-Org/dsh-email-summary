# 使用手册（Usage）

## 一、配置发信账号

1. 打开 **设置 → Plugins → 可配置 → 邮件通知**（默认折叠，点开）。
2. 选**邮箱服务商**（Gmail / QQ / 163 / 126 / Outlook / 自定义），自动填 SMTP 主机/端口/加密。
3. 填 **登录账号**（完整邮箱）、**发件人邮箱**、**默认收件人**（自动发送用）。
4. **密码/授权码**：QQ/163/126 用邮箱设置里生成的**授权码**（不是登录密码）。
5. 选**总结详略**（详细 / 简短），点**保存**。

> 密码会写入凭证存储（环境变量 `EMAIL_SMTP_PASSWORD`），不会出现在设置里。

## 二、手动发送（每一条助手消息）

每一条助手消息操作行都有一个**「✈ 发送邮件」**按钮：

- 点击 → 自动总结当前**整个会话** → 通过 SMTP 发送到 [收件人]。
- 发送中按钮禁用（显示「发送中…」），失败在旁边显示灰色错误。
- 未指定收件人时使用设置里的「默认收件人」。

## 三、对话结束自动发送

在输入区左侧打开 **「结束后发送」** 开关：

- 开启后，本会话 agent 转为空闲时，自动总结并发送到默认收件人。
- 适合"一次对话完成，自动把结论发到邮箱"的场景。
- 该开关是**会话级**的（Armed 状态在内存中，DSH 重启会丢失）。

## 四、出站代理

插件自动读取（优先级）：`HTTPS_PROXY` / `HTTP_PROXY` / `ALL_PROXY` 环境变量 → Windows 系统代理。

- 支持 HTTP `CONNECT` 和 SOCKS5。
- 例：`$env:HTTPS_PROXY="http://127.0.0.1:12345"`，Clash/V2Ray 混合端口直接可用。

## 五、实际场景示例

### 场景 A：把一次代码评审的结果发到团队邮箱

1. 设置里选「QQ 邮箱」或「163」预设，填账号 + 授权码 + 默认收件人。
2. 对话结束后，点助手消息上的「✈ 发送邮件」。
3. 邮箱收到带日期前缀、排版好的 HTML 总结。

### 场景 B：让每次开发对话自动归档

1. 在输入区打开「结束后发送」。
2. 正常对话；agent 空闲时自动把总结发到默认收件人。
3. 手动按钮仍可随时手动触发。

### 场景 C：用 Gmail（国内需代理）

1. 设置里选「Gmail」预设（`smtp.gmail.com:587 STARTTLS`）。
2. 设置 `HTTPS_PROXY` 指向本地代理，或确保系统代理可用。
3. 保存账号（Gmail 建议用应用专用密码）后发送。

## 六、邮件长什么样

- **标题**：`26年8月26日 dsh开发笔记：<简短标题>`（LLM 提炼）。
- **正文**：HTML，蓝色渐变标题栏 + 白底卡片 + 分段标题/列表/加粗/行内代码，内联样式。
- 底部标注"本邮件由 DSH 对话总结自动生成"。
